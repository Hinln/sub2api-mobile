# Vexlune Hub 管理端 UI 参考图核对

核对日期：2026-10-05（Asia/Shanghai）

核对范围：`design-reference/8.png` 至 `design-reference/16.png` 与 iPhone 17 Pro Max iOS 26.5 模拟器上的当前签名 Release 构建。所有列表和指标仍来自官方 Sub2API v0.2.13 管理接口；参考图中未由接口返回的数据没有补造。

## 结论

当前实现已经统一为浅色 Vexlune Hub 管理端视觉语言：浅蓝页面背景、单一浅色 V Logo、蓝色主色、圆角卡片、五栏底部导航和真实服务端数据。此前与参考图有明显差异的共性布局已修正：

- 顶部改为无外框 V Logo、品牌名、管理后台徽章和“稳定运行 · 高效管理”副标题。
- 概览页的运行明细、用户与账号池、趋势、最近失败默认展开，避免首屏只有空白折叠标题。
- 订单、公告、审计、异常等从 More 进入的页面补齐统一底部导航。
- 请求日志的“已记录”状态改为正常中文显示，不再出现字面量 `\\u5df2\\u8bb0\\u5f55`。
- 卡片内边距和圆角收紧，使列表密度更接近参考图。

## 仍不是像素级相同的地方

- 参考图的概览页有“平台运行稳定”、状态分布条和活动时间线；当前接口稳定返回的是连接状态、请求/计费/失败、Token、RPM、趋势和失败日志，因此使用这些真实字段呈现。
- 参考图的 More 页为分组行列表，当前保留了管理员专用的两列工具磁贴，以便在手机上快速进入异常、分组、公告、订单和审计功能。
- 参考图的账号、用户、分组列表更紧凑；当前卡片保留了服务端返回的并发、倍率、余额、描述和错误信息，信息量更大。
- `design-reference/1.png` 至 `7.png` 是普通用户工作台/登录相关参考图；当前产品定位是管理员专用 APP，因此没有恢复普通用户工作台。
