# 后端缺口与未盲目实现项

以下项目没有在已审计管理路由中发现适合当前移动端的完整、低风险能力，因此未放置虚假按钮：

- 全局 API Key 列表只有分组更新路由；当前从用户详情进入真实的用户 API Key 列表。
- 管理端支付订单/充值订单列表未在 `RegisterAdminRoutes` 中发现稳定入口；不以用户端支付接口代替。
- 密码重置邮件的管理员专用接口未确认；未实现。
- Dashboard 成功率、毛利率和特定错误字符串聚合缺少单一稳定接口；仅展示后端真实统计及最近失败日志。
- 账号 OAuth 添加流程涉及各 Provider 的浏览器回调、验证码和服务端配置，本版本不在 APP 收集第三方密码，也不伪造 OAuth。
- 系统设置字段数量大且版本敏感；当前只读展示连接/版本，未盲目提交整个 settings 对象。

真实 Vexlune 管理凭据未提供，故生产只读联调没有执行。所有视觉数据仅由 Playwright 路由拦截提供，不存在于生产包运行逻辑。
