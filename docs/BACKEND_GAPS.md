本文件记录截至 2026 年 8 月 2 日的管理员 API 审计和客户端接入状态。审计依据为 `Wei-Shaw/sub2api@7e2e9ba05026b7126318aa0754c1afa0ac00bc58` 的路由与处理器，以及本仓库当前实现；生产 Hub 未使用真实管理员凭据做写入联调。

## 财务口径限制

- `/payment/dashboard` 返回的是支付订单聚合，可作为“实收”展示，但不能自动等同于会计口径的已确认收入。
- `/dashboard/models` 的 `cost` 与 `actual_cost` 是模型用量计费聚合；它们不是上游供应商结算成本。
- 已验证接口没有提供覆盖各渠道、折扣、退款和结算周期的上游成本，因此 `利润 = 收入 - 上游成本` 无法可靠计算。客户端必须显示“不可计算”或 `--`，不能用标准价与实际扣费之差冒充利润。

## 其他已知边界

- 全局 API Key 管理：目前只验证并接入按用户读取 API Key，没有启用全局 Key 列表和写管理。
- 管理员密码重置：没有确认管理员专用的密码重置邮件流程。
- Dashboard 成功率：只有后端明确返回成功/失败聚合时才展示；不能从单页历史日志推算全日成功率。
- 账号 OAuth 添加：不同 Provider 依赖浏览器回调、验证码及服务端配置。移动端不收集第三方密码，也不伪造 OAuth 流程。
- 系统配置写入：`GET /api/v1/admin/settings` 已验证，但客户端未提交完整 settings 对象。

## 客户端处理规则

1. 只把已验证且已实现的能力标为“已接入”。
2. 缺失字段显示 `--`、“不可计算”或“不适用”，不转换为 0、正常或其他业务结论。
3. 请求日志与管理员操作日志严格区分；实收、用户扣费、标准参考价、上游成本和利润严格区分。
4. 高风险写操作必须有明确契约、权限边界和受控联调结果，不能仅因后端存在路由就默认开放。

真实管理员凭据未写入源代码、文档、测试数据或构建产物。
